# github-achievements-lab

Lab & playbook untuk unlock achievement GitHub profil — aksi nyata, di repo milik sendiri, tanpa spam ke pihak ketiga.

**Status eksperimen (2026-11-12):**

| Badge | Aksi di repo ini |
|---|---|
| Pull Shark | 11 PR playbook di-merge (self-merge dihitung) |
| Quickdraw | issue #1 dibuka & ditutup < 5 menit |
| YOLO | semua PR di-merge tanpa review |
| Pair Extraordinaire | PR #6 commit `Co-authored-by:` (uji: co-author diri sendiri) |
| Galaxy Brain | 2 diskusi Q&A self-answered + accepted (uji) |

**Playbook:** [docs/00-overview.md](docs/00-overview.md) — 15 badge: syarat, tier, mana yang bisa difarming di repo sendiri.

Prinsip: semua aksi nyata & terdokumentasi; eksperimen yang tidak pasti dilabel jelas; tidak menyentuh repo orang lain.
