# Pair Extraordinaire — deep dive

Co-authored commit yang di-merge lewat PR. Tier 1/10/24/48.

```text
Trailer di commit message: `Co-authored-by: Nama <email>`
Email harus milik akun GitHub (noreply format: <ID>+<login>@users.noreply.github.com)
Yang menerima badge: author PR (dan co-author yang bisa diresolusi ke akun)
Eksperimen repo ini: author == co-author (diri sendiri) — sedang diuji
```

> Kalau co-author sendiri tidak dihitung, butuh satu akun kedua; tier 10/24/48 butuh konsistensi trailer di setiap PR.
