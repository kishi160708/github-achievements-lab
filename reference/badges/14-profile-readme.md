# Profile README

Repo publik bernama sama dengan username → kontennya jadi bio profil.

```text
Buat repo `kishi160708/kishi160708` publik
Isi README.md menjadi kartu profil
Bisa menampilkan badge otomatis via gambar `?achievement=<name>`
```

> Trik populer: badge yang sudah didapat bisa ditampilkan ulang dengan URL `https://github.com/<user>?achievement=pull-shark&tab=achievements`.
