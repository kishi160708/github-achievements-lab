# gh pr

Siklus hidup pull request.

```text
`gh pr create -f title=... -f head=... -f base=main` — (via gh api) atau `gh pr create --fill`
`gh pr view <n> --json state,headRefOid,commits` — verifikasi state PR
`gh pr checks <n>` — status CI per check
`gh pr merge <n> --merge` — merge (tanpa review = YOLO)
`gh pr list --search "..."` — cari sebelum bikin duplikat
```

> Klaim 'sudah merged' hanya sah dari `state,mergedAt` yang dibaca ulang, bukan dari echo push.
