# gh search

Pencarian lintas GitHub.

```text
`gh search prs --author kishi160708 --merged --json totalCount` — PR merged milik sendiri (bukti farming!)
`gh search issues "keyword" --repo o/r`
`gh search repos "topic" --stars '>100'`
```

> Query `author:<user> is:pr is:merged` adalah cara resmi menghitung Pull Shark progress.
