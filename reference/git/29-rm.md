# git rm

Menghapus file dari working tree dan/atau index.

```text
`git rm <file>` — hapus + stage penghapusan
`git rm --cached <file>` — keluarkan dari index, file tetap di disk
`git rm -r <dir>` — rekursif
```

> `--cached` adalah cara benar berhenti menrack file (mis. secret yang tidak sengaja tercommit) tanpa menghapus salinan lokal.
