# git stash

Menyimpan sementara perubahan yang belum di-commit.

```text
`git stash` — simpan perubahan
`git stash list` — daftar stash
`git stash pop` — terapkan + hapus stash teratas
`git stash apply stash@{2}` — terapkan tanpa hapus
```

> Stash perubahan orang lain di shared tree jangan dibuang; commit di path milikmu sendiri, biarkan milik mereka.
