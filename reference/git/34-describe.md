# git describe

Nama yang dibaca manusia untuk commit berdasarkan tag terdekat.

```text
`git describe` — contoh: v1.2-3-gabc1234
`git describe --tags` — sertakan tag ringan
`git describe --dirty` — tandai working tree kotor
```

> Dipakai embed versi build: 3 commit setelah v1.2, di commit abc1234.
