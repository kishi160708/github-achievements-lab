# git remote

Mengelola remote repository.

```text
`git remote -v` — daftar remote + URL
`git remote add <nama> <url>` — tambah remote
`git remote set-url <nama> <url>` — ganti URL (mis. HTTPS↔SSH)
```

> Repo tanpa remote = publikasi butuh keputusan pembuatan repo; cek `git remote -v` sebelum berencana push.
