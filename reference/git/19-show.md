# git show

Menampilkan objek Git (commit, tag, tree).

```text
`git show <sha>` — detail satu commit
`git show <sha>:<path>` — isi file pada commit itu
`git show --stat <sha>` — ringkasan file yang berubah
```

> Cara paling murah mengklasifikasikan 'siapa mendaratkan file ini' sebelum commit ulang yang identik.
