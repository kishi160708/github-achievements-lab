# Galaxy Brain

Jawabanmu di GitHub Discussions ditandai sebagai accepted answer.

| Tier | Accepted answers |
|---|---|
| Default | 2 |
| Bronze | 8 |
| Silver | 16 |
| Gold | 32 |

Kategori harus format Q&A. Eksperimen repo ini: buka diskusi sendiri, jawab sendiri, tandai accepted sendiri. Badge diberikan pada POSTER jawaban yang di-accept. Jika self-accept tidak dihitung, butuh partisipan lain.
