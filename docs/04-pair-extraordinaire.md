# Pair Extraordinaire

Co-authored commit yang di-merge lewat PR.

| Tier | Merged PR dengan co-author |
|---|---|
| Default | 1 |
| Bronze | 10 |
| Silver | 24 |
| Gold | 48 |

Cara: commit dengan trailer

    Co-authored-by: Nama <email@users.noreply.github.com>

Email harus terhubung ke akun GitHub. Eksperimen repo ini: co-author = akun sendiri (author == co-author). Jika badge tidak terpicu, butuh akun GitHub kedua sebagai co-author.
