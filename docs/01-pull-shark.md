# Pull Shark

Diberikan saat PR kamu di-merge (di repo mana pun).

| Tier | Merged PR |
|---|---|
| Default | 2 |
| Bronze | 16 |
| Silver | 128 |
| Gold | 1024 |

Cara: bikin PR kecil yang nyata (dokumentasi, perbaikan typo, tests) lalu merge. Di repo sendiri, self-merge dihitung. Badge muncul dengan delay hingga ~24 jam.
