# Metodologi lab ini

1. Semua aksi nyata, di repo milik sendiri. Tanpa spam, tanpa menyentuh repo orang lain.
2. Konten playbook = dokumen nyata yang berguna, di-merge lewat PR nyata (sekaligus memicu Pull Shark/YOLO).
3. Verifikasi: halaman `?tab=achievements` profil + hitungan `is:pr is:merged author:kishi160708`.
4. Badge bisa delay hingga ~24 jam — verifikasi ulang esok.
5. Eksperimen dengan hasil tidak pasti (co-author sendiri, self-accept diskusi) didokumentasikan apa adanya.
